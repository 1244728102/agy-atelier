# AGY 专属工坊壁纸 (`agy-atelier`)

使用 `agy-atelier_skin` 工具控制 Antigravity 专属壁纸与工坊皮肤：

- `atelier_open_ui`：打开 **专属壁纸** 设置面板。
- `atelier_apply`：应用或更新壁纸皮肤（支持 `themeMode`: `dark`/`light`、`opacity`: `0.2`–`1.0`、`blur`: `0`–`30`、`accent`、`showLace`: `true`/`false`、`wallpaperPath`）。
- `atelier_clear`：一键还原 Antigravity 原生界面（卸载全部注入 DOM/CSS）。
- `atelier_status`：查看当前壁纸配置与注入状态。
